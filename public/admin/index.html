        Web Embed

        Placement & Container

        Default: Put the <script> tag where you want the view to appear. It creates a container directly after itself.

        Custom container: Place <div data-sissi-embed data-sissi-view="<view-id>"></div> anywhere on the page, and the script will mount inside it.

        Width Management

        Define the max-width on your embedding page using either:

        • Attribute: data-sissi-max-width="600px" (accepts px, rem, %, vw, or plain number for pixels)
        • CSS variable: --sissi-max-width: 600px; on the container or host element
        • Iframe: Query parameter ?maxWidth=600px or CSS max-width on the <iframe>

        Background Color

        Defaults to transparent so your site background shows through even with forced aspect ratios. Customize via:

        • Attribute: data-sissi-background="#ffffff" (or CSS variable --sissi-bg: #ffffff;)
        • Iframe: Query parameter ?background=%23ffffff
